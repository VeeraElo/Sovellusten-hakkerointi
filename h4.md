## c) If backwards
Tässä tehtävässä pitää muokata niin, että salasana hyväksyy kaiken muun paitsi oikean salasanan. Käynnistin passtr tiedoston ghidrassa ja etsin main sivun. Siellä löysin heti sen rivin missä salasana tarkistetaan `if (iVar1 == 0)`. 
Ideana oli heti muokata se `if (iVar != 0)`. Koska oikealla puolella olevaa ikkunaa(decompile) ei pysty muokkaamaan, etsin netistä tietoa. 
Tämä onnsitui muuttamalla(Patch Instruction) Listing ikkunasta JNZ -> JZ. JNZ, joka oli alunperin tarkoittaa Jump if not zero, eli hyppää, jos salasana on väärä. 
JZ = Jump if zero, eli hyppy tapahtuu vain jos tulos on 0. Eli se kääntyy. Oikea salasana -> wrong haara ja väärä salasana -> correct haara.

<img width="911" height="395" alt="ghidra-c-valmis" src="https://github.com/user-attachments/assets/5578f757-10df-456f-b0d6-3c49db8feaf6" />

Tämän muutoksen jälkeen menin file -> export program. Tallensin muokatun ohjelman passtr_mod nimisenä ja annoin sille ajo-oikeudet `chmod +x passtr_mod`. Tässä vielä kokeilu, että muutos toimi:

## d) Nora crackme
Nämä tehtävät ovat crackme-ohjelmia, joiden avulla on tarkoitus harjoitella käänteistekniikkaa analysoimalla binäärejä ja selvittämällä, millä syötteellä ohjelma palauttaa exit-koodin 0, ilman lähdekoodin tarkistelua.

Nora CrackMe: Compile to binaries Tindall 2023: [NoraCodes / crackmes ](https://github.com/NoraCodes/crackmes)

## e) Nora crackme01
Latasin ensimmäisenä kaikki nora crackmes virtuaalikoneelle.
```
git clone https://github.com/NoraCodes/crackmes.git
```

make crackme01
